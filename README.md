# Studio Gallery Mixed Reality (MR) Viewer

A free WebXR tool built with Three.js for viewing SketchUp corridor designs in Meta Quest 3 full-color passthrough mode.

## Files included in this package:
- `index.html`: The main WebXR application with fine-tuning controls.
- `README.md`: This instruction manual.

## Instructions for GitHub Setup:
1. Create a public repository on GitHub named `corridor-mr-gallery`.
2. Upload `index.html`, `README.md`, and your 5 exported SketchUp files (`design1.glb`, `design2.glb`, `design3.glb`, `design4.glb`, `design5.glb`).
3. Enable GitHub Pages under **Settings -> Pages -> Branch: main -> Save**.
4. Open the hosted URL in Meta Quest Browser, pick a design, and click **START AR**.
